# Custom-DistilBERT-Implementation-Fine-Tuning-for-Fine-Grained-Intent-Classification
Architected the DistilBERT transformer model from scratch using Keras model subclassing (EncoderBlock, DistilBertBackbone, and DistilBertIntentClassifier) and manually mapped 66.36M pretrained Hugging Face safetensors weights into TensorFlow/Keras. Verified weight alignment via masked-language-model inference, analyzed layer-wise parameter shifts during fine-tuning, and trained the model on the Banking77 dataset across 77 customer intent classes, achieving 92.40% test accuracy and a 0.9241 macro F1-score alongside a reusable top-k inference pipeline.
