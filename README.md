# Custom-DistilBERT-Implementation-Fine-Tuning-for-Fine-Grained-Intent-Classification
Architected the DistilBERT transformer model from scratch using Keras model subclassing (EncoderBlock, DistilBertBackbone, and DistilBertIntentClassifier) and manually mapped 66.36M pretrained Hugging Face safetensors weights into TensorFlow/Keras.
